# Pioneer机顶盒/电视红外协议记录

本文记录通过 ESP32-S3 和 Arduino-IRremote 4.7.1 实测得到的
Pioneer 机顶盒/电视遥控命令。

## NEC 命令

以下命令均为 32 bit NEC 协议：

| 按键 | 地址 | 命令 |
| --- | ---: | ---: |
| 音量 + | `0xAA` | `0x0A` |
| 音量 - | `0xAA` | `0x0B` |
| 频道 + | `0x00` | `0xF2` |
| 频道 - | `0x00` | `0xF4` |
| 电视电源 | `0xAA` | `0x1C` |
| 确认 | `0x00` | `0xF3` |

Arduino-IRremote 发送示例：

```cpp
IrSender.sendNEC(address, command, 0);
```

## 机顶盒电源

机顶盒电源命令在 Arduino-IRremote 中被识别为 `UNKNOWN`。连续采集
4 次的数据结构和总时长一致。普通解调接收头无法测量载波频率，
固件可通过串口菜单 `6` 在 40、56、36、38 kHz 之间循环测试。

- 总有效时序数：85
- 总时长：约 67.95 ms
- 帧结构：24 bit 数据 + 第二段引导码 + 16 bit 数据
- 引导码：约 `3650 us mark + 1800 us space`
- 数据 mark：约 `550 us`
- 逻辑 0 space：约 `550 us`
- 逻辑 1 space：约 `1100 us`
- 第一段数据（按发送顺序）：`0xF2C272` / 24 bit
- 第二段数据（按发送顺序）：`0xF00F` / 16 bit

该命令是无状态的电源切换命令，设备不会通过红外回传当前开关状态。

## Apple Home 映射

- 家庭 App 配件名称：`Pioneer机顶盒`
- 家庭 App 磁贴：仅显示电源开关，发送电视电源 `NEC 0xAA/0x1C`
- Apple TV 遥控器上/下/左/右/中央键：发送机顶盒五向导航命令
- iPhone 音量键：音量 +/-
- Apple TV 遥控器其他未学习键：不发送红外命令

### 机顶盒五向键数据

五个命令使用与机顶盒电源相同的波形结构，前 24 bit 固定为
`0xF2C272`，后 16 bit 如下：

| 按键 | 后 16 bit |
| --- | ---: |
| 上 | `0xD42B` |
| 下 | `0xA45B` |
| 左 | `0x946B` |
| 右 | `0x14EB` |
| 确认 | `0x34CB` |

固件直接重放实体遥控器的实测时序：段头 `1800 us`、逻辑 0
`550 us`、逻辑 1 `1100 us`。普通解调接收头会引入 mark/space 失真，
因此回读结果不用作发送补偿值。

## 注意

电源命令是切换型命令。如果使用实体遥控器改变机顶盒状态，Apple Home
显示的开关状态可能与实际设备不同步。
